## 2. SERP overlap matrix

Methodology: For each keyword pair within the same candidate cluster, both queries were
run via WebSearch and the top-10 organic result domains were compared. A shared URL
(same domain + same path prefix) scores 1 point; same domain different path scores 0.5.
Scores are rounded to integer.

Thresholds applied:
- 7-10: same post (consolidate)
- 4-6: same cluster (hub-spoke)
- 2-3: interlink only
- 0-1: separate, no forced link
